📊 Data Analyst Resources

A curated and organized collection of resources for aspiring and working Data Analysts, BI Analysts, Business Analysts, and Data Professionals.

This repository is designed as a practical resource hub covering SQL, Excel, Power BI, Python, Data Analytics, Generative AI, interview preparation, internships, career roadmaps, projects, and job searching.

🎯 Purpose

The goal of this repository is to keep useful Data Analytics resources in one place so you can follow a simple path:

Learn → Practice → Build Projects → Prepare → Apply → Get Hired

Whether you are starting your Data Analyst journey or preparing for interviews, these resources can help you structure your learning.

⭐ How to Use This Repository

Don't try to study everything at once.

Step 1 — Pick one skill

Start with SQL, Excel, Power BI, or Python.

Step 2 — Learn the fundamentals

Use the notes and learning resources provided here.

Step 3 — Practice

Solve SQL queries, Excel exercises, dashboard tasks, and analytics problems.

Step 4 — Build projects

Turn what you learn into real-world projects.

Step 5 — Document your work

Add your projects to GitHub and create a strong portfolio.

Step 6 — Prepare for interviews

Use the interview resources and practice platforms.

Step 7 — Apply consistently

Use the job-search resources to find relevant opportunities.

For large PDFs:

Use Git LFS, or

Host the file on Google Drive / OneDrive and add the resource link here.

Avoid committing unnecessarily large files directly to the repository.
